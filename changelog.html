Version 1.1.0 October 24, 2026

A more comfortable everyday planner

  • Added this changelog, now linked from Settings and the site footer.
  • Kept keyboard focus on a task checkbox after updating it. If a filter hides that task, focus moves to the next task or the empty-state message.
  • Made task delete controls visible on touch devices, where hover isn’t available.

Daymark remains a static, browser-based planner. Tasks and preferences stay in your browser; this release adds no account, analytics, advertising, or external runtime services.
