# Daymark

Daymark is a calm daily planner for organizing tasks and making space for focused work. It is a static website built with HTML, CSS, and vanilla JavaScript.

## Getting started

Open `index.html` in a browser to use Daymark. No build step or package installation is required.

## Features

- Plan and filter tasks for today, with upcoming tasks grouped by date.
- Use the focus timer and choose a task to work on.
- Personalize the welcome message in Settings.
- Export and restore a JSON backup, or clear locally saved data.
- Store tasks, preferences, and timer state in the browser's local storage.

## Pages

- `index.html` — Today
- `upcoming.html` — Upcoming tasks
- `focus.html` — Focus timer
- `settings.html` — Preferences and data management
- `privacy.html` and `terms.html` — Legal information
